## A shared product goal

Help a researcher answer: what evidence exists for this target, what is missing for the stated question, what observation would close that gap, and what can this graph safely rank?

The original application concerned an AD/PD/ALS gap atlas. The competition entry uses Pharos as its core, and that atlas can become a separate, provenance-preserving input. Start with a public, reproducible Pharos target-gap workflow; add one disease-context example only when its evidence is available and its scope can be stated. Keep expression association, causal support, assay sensitivity and Pharos development grade as distinct evidence types.

Example workflow to test with a researcher:

1. Choose a disease question and resolve a target without guessing an ambiguous name.
2. Read the supporting relationship and follow its source row, study and file digest.
3. Ask for the target's Pharos evidence gaps. Inspect the exact criterion, restoration condition and backtest population.
4. If a ligand gap is relevant, state the family's potency threshold; do not invent a distance when no sub-threshold measurement is loaded.
5. Separate a missing measurement from a measured null or context mismatch. Choose a feasible evidence-gathering action and explain which gap it could close.
6. Replace a fixture source with new evidence. The old derived output must be detected as stale; rebuild the affected portion and show why the gap closes, changes or retires. Unrelated gap identities should stay stable.

This workflow can meet usability, explainability and standards together, while the frozen prediction/pruning evaluations provide separate accuracy evidence. It also tests a research decision, rather than only whether an answer can be retrieved.

The scope deliberately distinguishes closing a documentation grade gap from discovering function. More papers can move a Pharos grade without answering the researcher's biological question. A proposed assay is useful only if its endpoint could resolve that specific missing evidence.
