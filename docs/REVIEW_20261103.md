Those can crash later string operations or create an empty study key. They now refuse non-text/blank metadata, malformed DOI and invalid dates before opening the supplied file or writing a sidecar. An unknown check stage is refused rather than silently treated as mapping. New tests exercise all three tool entry points without needing a real source file, API key or bundle.
